# 课堂词汇打卡小程序 MVP

这是一个基于微信小程序原生语法实现的 MVP，用来验证下面这条产品假设：

> 老师发布“当天课堂重点词”，系统自动生成闯关式练习，学生完成后自动返回结果，老师无需逐个批改，也能知道学生掌握情况。

## 这版做了什么

- 老师端发布任务
  - 输入任务标题、截止时间、老师备注
  - 按 `word | 中文释义` 的格式批量录入重点词
  - 系统自动预览词汇内容
- 学生端闯关打卡
  - 根据老师发布的词汇自动生成题目
  - 题型包含选择题、拼写题
  - 完成后自动计算分数、记录耗时、提取错词
- 老师端自动报告
  - 查看任务完成率、平均分
  - 查看每位学生是否完成、得分、耗时、错词
  - 汇总高频错词

## 适合演示的路径

1. 打开首页，看产品定位和当前演示数据。
2. 进入老师端，直接用示例词或手动改词后发布任务。
3. 进入学生端，切换一个学生身份开始闯关。
4. 完成题目后进入结果页，看到分数和错词。
5. 回到老师端报告页，查看自动汇总的数据。

## 如何运行

1. 打开微信开发者工具。
2. 选择“导入项目”。
3. 导入本项目目录。
4. 使用测试号或游客模式打开即可。

项目使用原生微信小程序目录结构，没有额外依赖，也不需要先跑构建命令。

## 这版为什么是 MVP

这版刻意只保留最核心的价值闭环，没有一开始就做复杂能力：

- 已做
  - 文本快速发布
  - 自动出题
  - 自动判分
  - 老师端结果汇总
- 未做
  - 拍照 OCR 导入单词
  - 语音输入发布任务
  - 发音音频
  - AI 例句和智能释义
  - 家长周报
  - 错词间隔复习

## 下一步建议

- 产品方向
  - 增加“错词二次复习”而不是只给分数
  - 增加家长可见的学习日报，强化付费感知
  - 增加按课次沉淀的词汇库，方便老师复用
- 工程方向
  - 接入云开发或后端服务，替代本地存储
  - 增加班级、老师账号、学生账号体系
  - 接入 OCR 和语音识别，提高老师发布效率
